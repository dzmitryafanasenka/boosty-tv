# Политика безопасности

Поддерживается только последний релиз.

Об уязвимости сообщайте приватно через GitHub: **Security → Report a
vulnerability** в этом репозитории. Не создавайте публичный issue и не
прикладывайте настоящие токены, cookies, номера телефонов или коды входа.

---

## Security policy

Only the latest release is supported.

Report a vulnerability privately through GitHub: **Security → Report a
vulnerability** in this repository. Do not open a public issue, and do not
include real tokens, cookies, phone numbers or sign-in codes in the report.
