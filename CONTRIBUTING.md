# Contributing

Boosty TV is open source, but it is maintained by a single person and does
**not accept code contributions**. Pull requests from outside the project are
closed automatically, without review. This keeps the scope, security rules and
release signing in one place.

You are welcome to help in other ways:

- **Report a bug** — open an issue with the «Ошибка / Bug report» template.
- **Suggest an idea** — open an issue with the «Идея / Feature idea» template.
  The maintainer decides whether and how an idea is implemented.
- **Report a vulnerability** — do not open a public issue; see
  [SECURITY.md](SECURITY.md).

The MIT licence still lets you fork the code and change it in your own copy.

Never post a phone number, a sign-in code, tokens, cookies, signed media links
or screenshots with personal data in an issue.

## Как помочь проекту

Boosty TV — открытый проект, но его ведёт один человек, и **изменения в код
со стороны не принимаются**. Pull request'ы от сторонних авторов закрываются
автоматически, без рассмотрения.

Чем можно помочь:

- **Сообщить об ошибке** — создайте issue по шаблону «Ошибка / Bug report».
- **Предложить идею** — создайте issue по шаблону «Идея / Feature idea».
  Решение о реализации принимает автор проекта.
- **Сообщить об уязвимости** — не в публичном issue, а по
  [SECURITY.md](SECURITY.md).

Лицензия MIT позволяет сделать форк и менять код в своей копии.

Не публикуйте в issue номер телефона, код входа, токены, cookies, подписанные
ссылки на медиа и скриншоты с личными данными.
