# Boosty TV — карта фокуса

Общие правила:
- Управление: D-pad, OK, Back, медиаклавиши (Play/Pause, FF/Next, Rew/Prev, Menu/Info).
- **Без зацикливания.** На краю списка нажатие ничего не делает, кроме описанных переходов в соседнюю зону.
- Зоны: `sidebar ↔ content ↔ filters/panels ↔ grid ↔ dialogs`. ← из первой колонки контента всегда ведёт в сайдбар на текущий раздел; → из сайдбара возвращает на последний фокус контента.
- **Модальное окно и боковая панель изолируют фокус.** При закрытии фокус возвращается на элемент-инициатор.
- **Исчезнувший элемент:** фокус переходит на соседа по индексу в том же списке; если список пуст — на ближайшее действие выше (поле, кнопка фильтров, «Назад»).
- **Подгрузка и обновление не двигают фокус.** Идентичность — по `post id`, `blogUrl`, `video id`, а не по индексу.
- Переключение раздела — только по OK, не при наведении.
