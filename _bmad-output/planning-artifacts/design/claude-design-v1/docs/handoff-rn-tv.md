# Boosty TV — handoff для React Native TV

Стек: React Native + `react-native-tvos`, Android TV / Google TV (Chromecast with Google TV 4K). Apple TV (tvOS) is out of scope (owner decision 2026-10-27).

HTML-макеты и прототип — иллюстрация. Поведение фокуса проверяется только на устройстве.

## Единицы

Макет 1920×1080 → 960×540 dp. **Делите px макета на 2.** Пример: карточка 336×189 px → 168×94.5 dp; safe area 96/54 px → 48/27 dp.

## Layout constraints

- Корень экрана: `flexDirection: row`; `Sidebar` фиксированной ширины 168 dp; контент `flex: 1`, отступ слева 24 dp, справа 48 dp (safe area).
- Сетки — фиксированные ширины колонок, не `flex: 1`. Карточка 168 dp, шаг 16 dp; плитка автора 232 dp, шаг 12 dp.
- Ряды и сетки получают внутренний отступ 12 dp, чтобы масштаб 1.06 не обрезался. `overflow: visible` у строк, `removeClippedSubviews` выключен для видимых рядов.
- Текст: `numberOfLines` для заголовков карточек (2), заголовка поста (6), названия блога (2). Нигде не растягиваем высоту карточки под текст.
- Модальные окна и `SideSheet` рендерятся поверх экрана в одном `Modal`/портале, фон приглушается, ввод под ними не доходит.

## Виртуализация списков (допущения)

| Список | Компонент | Допущения |
|---|---|---|
| Лента, публикации автора, результаты поиска | `FlatList` `numColumns={4}` | Фиксированная высота ряда → `getItemLayout`. `windowSize` ≈ 5, `initialNumToRender` = 8. Подгрузка при фокусе за 2 ряда до конца, не по `onEndReached` прокрутки |
| «Продолжить просмотр» | горизонтальный `FlatList` | До 20 элементов, без подгрузки |
| Подписки | `FlatList` `numColumns={3}` | Длинный список 50+; `getItemLayout` по высоте ряда 88 dp. Пагинация E2 не подтверждена |
| Вложенные ряды на Главной | Внешний вертикальный `FlatList` со строками | Ряд «Продолжить» и заголовки — отдельные элементы списка |
| Контент поста | `ScrollView` | Блоков мало. Прокрутка к фокусу вручную через `scrollTo` по `onLayout` блока |
| События | `FlatList` | Формат пагинации E18 неизвестен |

Ключи элементов — `post.id`, `blog.blogUrl`, `video.id`, а не индексы. Слияние страниц — с удалением дублей по id (FEED-02).

## Focus ID и восстановление

Схема: `<screen>/<zone>/<id>`.

| Пример | Значение |
|---|---|
| `nav/home` … `nav/settings` | Пункты сайдбара |
| `home/continue/<videoId>` | Карточка «Продолжить» |
| `home/feed/<postId>` | Карточка ленты |
| `home/feed/retry` | Повтор подгрузки |
| `subs/tile/<blogUrl>` | Плитка автора |
| `author/<blogUrl>/action/search \| filters \| reset` | Действия автора |
| `author/<blogUrl>/live`, `/live/like`, `/live/share` | Эфир |
| `author/<blogUrl>/post/<postId>` | Публикация |
| `filters/access/<value>`, `filters/period`, `filters/tag/<tagId>` | Панель фильтров |
| `post/<postId>/primary`, `/restart`, `/video/<videoId>`, `/file/<n>`, `/link/<n>`, `/poll/option/<optionId>` | Пост |
| `player/timeline`, `player/playpause`, `player/settings`, `player/sheet/quality/<q>` | Плеер |

- Перед переходом вперёд экран сохраняет `{focusId, scrollOffset}` в стек навигации. При возврате — сначала прокрутка, затем `requestTVFocus` / `hasTVPreferredFocus` на сохранённый id.
- Если id не найден (элемент исчез после обновления) — сосед по индексу в том же списке, затем первый элемент зоны.
- Границы зон: `TVFocusGuideView` с `destinations` для переходов sidebar ↔ content и ряд ↔ ряд по горизонтальной позиции. `trapFocusUp/Down/Left/Right` у `SideSheet` и `Dialog`.
- Обработка D-pad — через `useTVEventHandler` только на плеере, в настройках периода и аудиоблоке. Остальное — нативный фокус.
- Пока открыта системная клавиатура, приложение не перехватывает стрелки.

## Оверлеи плеера

| Слой | Показ | Скрытие | Back |
|---|---|---|---|
| Оверлей управления | OK, ↑ ↓, ← → (с пузырём), пауза, медиаклавиши | 5 с без ввода при воспроизведении. **Не скрывается** на паузе, при перемотке, с открытой панелью и при ошибке | Скрыть |
| Панель настроек | Кнопка «Настройки», Menu/Info/Settings | OK по варианту качества, Back, Menu | Подменю → панель → закрыть |
| Буферизация | Ожидание > 500 мс | Данные пошли | — |
| «Восстанавливаем воспроизведение…» | Любая ошибка плеера, 1-я попытка | Успех | — |
| Ошибка | 2-я ошибка подряд | «Повторить» | Выход |
| «Стрим завершён» | Окончание эфира | «Назад» | Выход |

Позиция видео пишется на сервер (E9): каждые ≥ 10 с сдвига, на паузе, при сворачивании, на выходе. Скорость запоминается глобально, качество — как предпочтение. В эфире скорость 1× и нет перемотки.

## Платформенные пометки

- «Системный видеоплеер» (PLAY-13) — только Android: `Intent.ACTION_VIEW`.
- QR генерируется на устройстве, подписанные URL в логи не пишутся (SET-05).
