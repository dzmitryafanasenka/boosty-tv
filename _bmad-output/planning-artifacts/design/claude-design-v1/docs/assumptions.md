# Boosty TV — допущения и условные элементы

**Улучшение клиента** — нет в BoostBuddy, добавлено нами. **Условно** — зависит от данных, которые API ещё не подтвердил. **Решение** — дизайн-решение, требует согласия владельца.

## Условные элементы

| Элемент | Статус | Почему | ID / источник | Что если не подтвердится |
|---|---|---|---|---|
| Ряд «Продолжить просмотр» | Улучшение клиента | Отдельного API со списком начатых видео нет. Локальная история на устройстве + серверная позиция `timeCode` | PLAY-03, PLAY-04 | Ряд пуст → не показывается |
| Длительность на карточке видео в ленте | Условно | Длительность `ok_video` в ответе не подтверждена. По умолчанию карточка без длительности (B7) | api-contract §4.1 | Остаётся вариант без длительности |
| Полоса прогресса | Условно | Возможна только при известной длительности. Длительность берём из локальной истории плеера | PLAY-03 | Текст «остановились на 33:05» без полосы |
| Длительность аудио | Есть в API | `audio_file.duration` | POST-06 | — |
| Описание и обложка автора | Не проектируем | Не подтверждены в E3 | AUTHOR-PAGE-01 | Добавить как необязательный блок под шапкой |
| События | Улучшение клиента, условно | E18 не вызывается из UI BoostBuddy, формат не проверен. Пункт сайдбара показываем только после проверки | EVT-01 | Пункт скрыт |
| Типы событий кроме `video_stream_start` | Условно | Показываем общим текстом | EVT-01 | — |
| Пагинация подписок | Условно | BoostBuddy берёт `limit=30` без пагинации | SUB-01, api-contract §8.9 | Заметка «Показаны первые 30 подписок» |
| «Мой блог» | Есть | Только если у профиля есть `blogUrl` и в блоге ≥ 1 пост | SUB-02 | — |
| Формы ошибок входа (неверный, истёк, лимит, проверка) | Условно | Ответы не наблюдались | api-contract §2.2 | Общий текст «Не удалось войти» |
| Канал доставки кода | Условно | `sentTransport` может отсутствовать | AUTH-03 | Общая подсказка про SMS / мессенджер / приложение |
| Длина кода | Неизвестна | Одно поле без ячеек | AUTH-03 | — |
| Время блокировки при лимите | Условно | Показываем, только если пришло от сервера | api-contract §7 | Без таймера |
| Капча | Потенциальный блокер релиза | Пройти на ТВ нельзя, обходов не делаем | Brief «Risks», spike S2 | Решение владельца |
| Различие 401 / 403 / 404 / 5xx | Условно | BoostBuddy их не различает. Сессия сбрасывается только при 401 после неудачного refresh | AUTH-05, AUTH-06, api-contract §7 | — |
| Срок жизни подписанных ссылок | Неизвестен | Одна автоматическая попытка восстановления | PLAY-10 | — |
| URL страницы эфира для QR | Есть | `boosty.to/{blog}/streams/video_stream` | LIVE-05 | — |
| Цена уровня подписки | Не показываем | Оплаты в приложении нет, показываем только название уровня | LIVE-01 | — |
| Передача журнала | Условно | Канал не утверждён, на макете — adb | SET-05 | QR или другой канал |

## Дизайн-решения на согласование

| Решение | Почему | Где |
|---|---|---|
| Защита от случайного OK в опросе с одним вариантом: 1-й OK отмечает, 2-й отправляет | BoostBuddy голосует сразу; на пульте OK нажимают, когда листают | I2 |
| Ссылки из текста — отдельными кнопками под абзацем | Двигать фокус внутри строки текста пультом неудобно | F1, F6 |
| Аудио — одна точка фокуса (OK = play/pause, ← → = перемотка) | Меньше переходов, нет конфликта стрелок | H1 |
| Абзацы раскрытого текста — точки остановки фокуса | Иначе длинный текст нельзя прокрутить пультом | F5 |
| Период фильтра — пресеты + «Свой период» со степперами | Веб-календарь не подходит для D-pad | D6, D7 |
| Диагностика открывается 7 нажатиями на «Версия» | Не мешает семье, доступна владельцу | K1 |
| «Отмена» — фокус по умолчанию в окне выхода | Выход затрагивает всех на этом ТВ | K3 |
| Сайдбар всегда раскрыт, без режимов compact/expanded | Режимы усложняют фокус; 336 px помещаются | B3 |
| Пауза в эфире разрешена, продолжение — с текущего момента | DVR отключён (LIVE-02) | G11 |
| Фильтры ленты и поиска — та же панель, что у автора | Одно поведение везде | D4, E1 |

## Ограничения прототипа

- HTML-прототип показывает логику фокуса, но не доказывает поведение нативного фокуса Android TV.
- Системная клавиатура нарисована условно; ввод — с физической клавиатуры.
- Фильтры ленты на Главной и в Поиске не открываются: панель реализована на странице автора (сценарий 5).
- Эфир завершается сам через 20 с просмотра, чтобы показать «Стрим завершён».
- Сбои сети, истёкшая ссылка и сессия вызываются кнопками симуляции под экраном.
