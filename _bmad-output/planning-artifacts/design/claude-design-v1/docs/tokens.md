# Boosty TV — дизайн-токены

Координаты дизайна: кадр 1920×1080. На Android TV 1080p = 960×540 dp, поэтому **1 dp = 2 px макета**. В RN-коде делите значения на 2. 720p даёт те же 960×540 dp, отдельной сетки нет.

Тема только тёмная (SET-03), токены именованы семантически, чтобы светлую тему можно было добавить без переименований.

## Отступы и сетка

| Токен | Значение |
|---|---|
| `safe.x` | 96 (5% ширины) |
| `safe.y` | 54 (5% высоты) |
| `sidebar.width` | 336 (текст пунктов с x = 96) |
| `content.x` | 384 |
| `content.width` | 1440 |
| `grid.card` | 4 × 336, шаг колонки 32, ряд 44 |
| `grid.author` | 3 × 464, шаг 24 |
| `space` | 4, 8, 12, 16, 20, 24, 28, 32, 40, 48, 56, 64 |
| `focus.headroom` | 24 по краям ряда — запас на масштаб, ничего не обрезается |

Safe area 5% — гипотеза. Обоснование композицией: подложка сайдбара и превью уходят в край, но весь текст и фокусные элементы лежат внутри 96/54 px. Пятая карточка ряда намеренно обрезается краем экрана как подсказка прокрутки; карточка в фокусе всегда целиком внутри 1824 px.

## Фокус

| Токен | Значение |
|---|---|
| `focus.ring.width` | 4 |
| `focus.ring.offset` | 4 |
| `focus.scale.card` | 1.06 (PostCard), 1.05 (AuthorCard), 1.03 (LiveCard) |
| `focus.scale.button` | 1.04 |
| `focus.scale.row` | 1.02 (строки, варианты опроса, видео в посте) |
| `focus.scale.field` | 1.0 — поля не масштабируются |
| `focus.shadow` | 0 18 40 rgba(0,0,0,0.5) у карточек |
| `pressed.scale` | 0.98 |

Фокус = контур + поверхность + масштаб, не только цвет. Текущий (selected/current) = оранжевая метка или отметка. Недоступный элемент не фокусируется.

## Движение

| Токен | Длительность | Кривая | Где |
|---|---|---|---|
| `motion.focus` | 160 мс | cubic-bezier(0.2, 0, 0, 1) | Масштаб и поверхность при смене фокуса |
| `motion.press` | 80 мс | linear | Нажатие |
| `motion.scroll` | 240 мс | cubic-bezier(0.2, 0, 0, 1) | Прокрутка к фокусу |
| `motion.panel` | 200 мс | cubic-bezier(0.2, 0, 0, 1) | Выезд боковых панелей |
| `motion.overlay.fade` | 200 мс | linear | Оверлей плеера |
| `motion.overlay.hide` | 5000 мс | — | Автоскрытие оверлея (PLAY-05) |
| `motion.seek.commit` | 600 мс | — | Применение новой позиции после перемотки |
| `motion.buffer.delay` | 500 мс | — | Задержка показа буферизации (PLAY-10) |
| `motion.spinner` | 900 мс / оборот | linear | Индикатор загрузки |

Никаких декоративных анимаций. При включённом «Уменьшить движение» в системе масштаб фокуса остаётся, прокрутка — мгновенная.
