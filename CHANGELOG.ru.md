# Изменения

Заметные изменения Boosty TV — неофициального клиента Boosty для Android TV / Google TV.
Версии в формате `MAJOR.MINOR.PATCH`; каждый релиз помечен тегом `v{версия}` в GitHub Releases.
Английская версия файла — [CHANGELOG.md](CHANGELOG.md); в обоих файлах одни и те же версии.

## [0.9.0] - 2026-11-01

Первый подписанный релиз для проверки на семейном телевизоре. Версия `1.0.0` зарезервирована за приёмкой владельцем.

### Добавлено
- Вход по номеру телефона и одноразовому коду; сессия сохраняется после перезапуска и обновляется сама. Быстрый повторный вход после истечения сессии, выход и смена аккаунта без утечки данных.
- Главная лента подписок с обновлением, рядом «Продолжить» и фильтрами по доступу, периоду и тегам.
- Сетка подписок с плиткой «Мой блог», страницы авторов с поиском и фильтрами, поиск по подпискам.
- Экран поста: форматированный текст, эмодзи, изображения, ссылки, файлы и внешние видео через QR, закрытые посты.
- Видеоплеер: выбор качества и скорости, сохранение прогресса и продолжение просмотра, восстановление после истёкших ссылок и ошибок воспроизведения, сон и аудиофокус, системный видеоплеер по выбору.
- Аудио в постах.
- Опросы: один и несколько вариантов, голосование и отмена голоса.
- Трансляции на страницах авторов: просмотр, лайки и «Поделиться» через QR; список событий.
- Скрытая диагностика для тестирования (запись логов).
- Финальный баннер для лаунчера и адаптивная иконка.

### Примечания
- Комментарии намеренно не поддерживаются.
- Установка поверх ранней тестовой сборки с другим ключом не проходит: удалите её один раз (потребуется повторный вход, локальный прогресс будет потерян). Следующие релизы ставятся поверх этого и сохраняют сессию.
